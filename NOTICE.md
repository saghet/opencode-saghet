# Atribuciones y Licencias de Terceros — OpenCode-Saghet

OpenCode-Saghet integra, referencia o configura los siguientes proyectos de terceros, conservando sus respectivos avisos de copyright y licencias:

1. **OpenCode (`anomalyco/opencode` v2.3.2)** — Licencia **MIT**
   - Motor CLI, TUI, servidor v2 y SDK base.
2. **OpenCode Agent Orchestration Kit (`jcarlosrodicio/opencode-agent-orchestration-kit` v1.2.0, commit `ac4bc52d03a1`)** — Licencia **Apache-2.0**
   - Patrón arquitectónico de contratos multiagente, gates de revisión y scripts de ciclo de vida.
3. **Plannotator (`backnotprop/plannotator` / `@plannotator/opencode` v0.29.0, commit `a305693458f1`)** — Licencia **MIT OR Apache-2.0**
   - Plugin de revisión visual interactiva de planes y diffs.
4. **OpenCode Memory (`opencode-mem` v2.43.0)** — Licencia **MIT**
   - Memoria persistente local con embeddings.
5. **OpenCode Dynamic Context Pruning (`@tarquinen/opencode-dcp` v3.2.1)** — Licencia **AGPL-3.0-or-later**
   - Plugin de poda y deduplicación de contexto.
6. **DBHub (`@bytebase/dbhub` v1.7.1)** — Licencia **Apache-2.0**
   - Servidor MCP para acceso SQL controlado a SQLite y PostgreSQL.
7. **Sequential Thinking MCP (`@modelcontextprotocol/server-sequential-thinking` v2.2.0)** — Licencia **MIT**
   - Servidor MCP de razonamiento estructurado.
